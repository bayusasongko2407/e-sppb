# Agent Checklists

## Before Coding

- [ ] Current phase allows coding.
- [ ] Relevant `.codex` guides loaded.
- [ ] Detailed `/docs` opened only as needed.
- [ ] Business rule traced.
- [ ] Database impact understood.
- [ ] Workflow impact understood.
- [ ] API/Flutter impact understood.
- [ ] Security and authorization considered.

## Code Review

- [ ] PSR compliant.
- [ ] SOLID.
- [ ] Service Layer used.
- [ ] No business logic in UI/controller.
- [ ] Policy used.
- [ ] Form Request/validation used.
- [ ] Tests available.
- [ ] Documentation updated.
- [ ] No frozen rule violation.

## Database

- [ ] Schema matches frozen plan.
- [ ] FK validated.
- [ ] Indexes appropriate.
- [ ] Naming verified against approved schema.
- [ ] Audit strategy met.

## Phase 0 Completion

- [ ] AI documentation structure exists.
- [ ] `AGENTS.md` exists.
- [ ] `.codex` knowledge base exists.
- [ ] Repository map exists.
- [ ] Prompt library exists.
- [ ] Checklists exist.
- [ ] Knowledge files generated from `/docs`.
