# Accessibility

## Target

Follow WCAG AA principles where practical.

## Requirements

- Keyboard accessible.
- Visible focus.
- High contrast.
- Screen reader friendly.
- Proper labels.
- Semantic HTML.
- Minimum touch target 44px.
- Color is never the only status indicator.

## Component Requirements

- Icon-only buttons have accessible labels.
- Modal/drawer traps focus.
- Form fields have labels and error associations.
- Tables expose meaningful headers.
