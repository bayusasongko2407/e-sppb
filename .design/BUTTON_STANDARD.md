# Button Standard

## Variants

- Primary: main page action.
- Secondary: normal actions.
- Tertiary/ghost: low emphasis actions.
- Danger: destructive actions.
- Icon: toolbar and compact actions.

## Sizes

- `button-sm`: table row actions and compact toolbars.
- `button-md`: default.
- `button-lg`: rare primary workflow actions.

## Rules

- One primary action per page area.
- Destructive actions require confirmation.
- Loading state must prevent duplicate submission.
- Disabled actions should provide reason when practical.
- Icon-only buttons require tooltip and accessible label.
