- Inputs.
- Select.

- Department Badge.
- Plant Badge.
- Dialogs.
- Drawers.
- Tabs.
- Wizard.
- Charts.
- Widgets.

## Component Rules

- Components consume tokens, never raw values.
- Components expose consistent states: default, hover, focus, active, disabled, loading, error where relevant.
- Components must support permission-aware rendering.
- Components must be keyboard accessible.
- Components must have empty/loading/error states where relevant.

## Reuse Rule

Before creating a new component, check whether an existing component can be extended.
