# Dashboard Standard

## Dashboard Is Not Just Statistics

Dashboard must support daily work and role-specific decision making.

## Required Widgets

- KPI Cards.
- Charts.
- Workflow Status.
- Approval Queue.
- Recent Activity.
- Notifications.
- Quick Actions.
- User Tasks.
- Timeline.
- Shortcuts.

## Role-Based Content

- Admin: system health, master data quality, user/activity summary.
- Requester: drafts, submitted SPPB, revision requests, recent documents.
- BAT/Manager: approval queue, SLA risk, pending decisions.
- Warehouse: approved documents, execution queue, validation status.
- Management: KPI, process throughput, SLA, trends.

## Rules

- Widgets must be permission-aware.
- Prioritize actionable widgets above passive charts.
- Dashboard layout must reflow responsively.
- Empty states must explain what is missing and what action to take.
