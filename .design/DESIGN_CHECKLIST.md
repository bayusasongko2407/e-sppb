# Design Checklist

## Before Creating Any Page

- [ ] Reviewed `DESIGN_SYSTEM.md`.
- [ ] Reviewed `UX_GUIDELINE.md`.
- [ ] Reviewed `COMPONENT_LIBRARY.md`.
- [ ] Reviewed `PAGE_TEMPLATE.md`.
- [ ] Reviewed this checklist.

## Visual Consistency

- [ ] Uses design tokens.
- [ ] No hardcoded colors.
- [ ] No hardcoded spacing.
- [ ] Typography follows scale.
- [ ] Components are reused.
- [ ] No duplicated UI pattern.

## Workflow Quality

- [ ] Page supports actual workflow, not only CRUD.
- [ ] Primary action is clear.
- [ ] Current state is visible.
- [ ] Next actions are obvious.
- [ ] Disabled actions explain why when practical.

## Tables

- [ ] Search.
- [ ] Quick filter.
- [ ] Advanced filter.
- [ ] Sorting.
- [ ] Column resize.
- [ ] Column visibility.
- [ ] Pagination.
- [ ] Bulk action.
- [ ] Export/import where relevant.
- [ ] Sticky header.
- [ ] Responsive layout.
- [ ] Empty/loading state.
- [ ] Permission-aware actions.

## Forms

- [ ] Auto/inline validation.
- [ ] Help text.
- [ ] Draft saving where relevant.
- [ ] Keyboard navigation.
- [ ] Progressive disclosure.
- [ ] Grouped sections.
- [ ] Tabs/wizard for large forms.
- [ ] Destructive confirmation.
- [ ] Readonly mode.
- [ ] Responsive layout.

## Accessibility

- [ ] Keyboard accessible.
- [ ] Visible focus.
- [ ] High contrast.
- [ ] Proper labels.
- [ ] Semantic HTML.
- [ ] Touch target >= 44px.
