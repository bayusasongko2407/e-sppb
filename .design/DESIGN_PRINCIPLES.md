# Design Principles

## Enterprise First

Design for staff who use the application for long daily sessions. Prioritize clarity, density, predictability, and speed over decorative presentation.

## Workflow Over CRUD

Pages must represent real workflows: request, submit, approve, revise, reject, validate, report, monitor. A data table alone is not sufficient for core workflows.

## Consistency

Use the same tokens, layout rules, component behavior, labels, icons, and action positions across modules.

## Context Preservation

Users should always know where they are, what document/status they are viewing, what actions are available, and what happens next.

## Error Prevention

Guide the user before mistakes happen through validation, disabled states with reason, confirmation for destructive actions, and clear status badges.

## Role Awareness

Dashboards, actions, table columns, widgets, navigation, and quick actions must respect role and permission.
