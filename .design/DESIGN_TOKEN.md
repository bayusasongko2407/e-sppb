# Design Tokens

Do not hardcode values in application components. Use token aliases.

## Token Categories

- Color: see `COLOR_SYSTEM.md`.
- Typography: see `TYPOGRAPHY.md`.
- Spacing: see `SPACING_SYSTEM.md`.
- Grid and breakpoints: see `GRID_SYSTEM.md`.
- Radius: `radius-none`, `radius-xs`, `radius-sm`, `radius-md`.
- Shadow: `shadow-none`, `shadow-xs`, `shadow-sm`, `shadow-md`.
- Border: `border-subtle`, `border-default`, `border-strong`, `border-focus`.
- Motion: `motion-fast`, `motion-normal`, `motion-slow`.
- Icon size: `icon-xs`, `icon-sm`, `icon-md`, `icon-lg`.
- Button size: `button-sm`, `button-md`, `button-lg`.
- Table density: `density-compact`, `density-standard`, `density-comfortable`.
- Card padding: `card-padding-sm`, `card-padding-md`, `card-padding-lg`.

## Naming Pattern

Use semantic tokens:

- `color-bg-page`
- `color-bg-surface`
- `color-text-primary`
- `color-action-primary`
- `space-4`
- `radius-sm`
- `shadow-xs`
