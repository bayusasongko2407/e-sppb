# Form Standard

## Required Capabilities

- Auto validation.
- Inline validation.
- Help text.
- Draft saving.
- Keyboard navigation.
- Progressive disclosure.
- Grouped sections.
- Tabs or wizard for large forms.
- Confirmation before destructive actions.
- Readonly mode.
- Responsive layout.

## Structure

1. Header with purpose and status.
2. Required core fields first.
3. Group related fields into sections.
4. Use tabs/wizard for long workflows.
5. Place submit/cancel actions consistently.

## Validation

- Validate early.
- Show errors near the field.
- Preserve entered data.
- Avoid generic error messages.

## Draft Saving

SPPB creation and long forms should support draft state where business rules allow.
