# Grid System

## Layout Strategy

Desktop first, with tablet and mobile support.

## Breakpoints

- `bp-sm`: mobile.
- `bp-md`: tablet.
- `bp-lg`: desktop.
- `bp-xl`: wide desktop.

## Page Grid

- Desktop pages use a constrained content width for forms and reports when readability matters.
- Data-heavy pages may use full available width.
- Avoid horizontal scrolling except inside intentionally constrained data-table containers with responsive fallback.

## Responsive Columns

- Desktop: 12-column grid.
- Tablet: 8-column grid.
- Mobile: 4-column grid.

## Rules

- Use stable widths for sidebars, toolbars, and table controls.
- Forms must collapse cleanly to one column on mobile.
- Dashboard widgets must reflow by priority.
