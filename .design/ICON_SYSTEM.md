# Icon System

## Principles

Icons support recognition and reduce visual load. They must not replace required accessible labels.

## Sizes

- `icon-xs`: table metadata, badges.
- `icon-sm`: buttons, inputs.
- `icon-md`: navigation, empty states.
- `icon-lg`: dashboard and page states.

## Rules

- Use one consistent icon family in implementation.
- Never mix unrelated icon styles.
- Icon-only buttons require tooltip and accessible label.
- Status icons must match status token semantics.
- Do not copy proprietary icons.
