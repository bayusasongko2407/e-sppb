# Mobile Guide

## Mobile Purpose

Mobile support must enable approvals, status checks, notifications, quick search, and essential document viewing.

## Rules

- One primary action per view.
- Use large touch targets.
- Avoid dense multi-column tables.
- Keep approval/rejection/revision actions easy to reach.
- Use bottom action area for critical workflow actions when appropriate.
- Do not hide important status or reason fields.

## Mobile Dashboard

Prioritize tasks, approvals, notifications, and shortcuts before charts.
