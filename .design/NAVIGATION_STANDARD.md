# Navigation Standard

## Required Navigation

- Collapsible sidebar.
- Breadcrumbs.
- Current page highlight.
- Favorites.
- Recently opened pages.
- Global search.
- Keyboard shortcuts.

## Navigation Groups

- Dashboard.
- Master Data.
- SPPB.
- Workflow.
- Monitoring.
- Laporan.
- Pengaturan.

## Rules

- Navigation labels must match domain language.
- Do not expose unauthorized pages.
- Preserve user location and state where practical.
