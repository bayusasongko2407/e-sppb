# Page Template

## Required Page Anatomy

1. Breadcrumb.
2. Page title.
3. Page description or context where useful.
4. Primary action.
5. Secondary actions.
6. Status/context summary.
7. Main content.
8. Filters/search where relevant.
9. Empty/loading/error states.
10. Permission-aware action states.

## Workflow Page

- Header: document number, status, requester, date.
- Main: document details and items.
- Side/context panel: workflow, approval queue, activity timeline.
- Actions: submit, approve, reject, revision, cancel according to permission and state.

## List Page

- Header and primary action.
- Search and quick filters.
- Advanced filter access.
- Table with required capabilities.
- Bulk actions.
- Export/import where relevant.

## Form Page

- Header and status.
- Sections/tabs/wizard.
- Inline validation.
- Draft save.
- Sticky action footer for long forms.
