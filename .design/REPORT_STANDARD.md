# Report Standard

## Report Principles

Reports must be readable, filterable, exportable, and traceable to source data.

## Required Capabilities

- Date range filter.
- Status filter.
- Organization filter where relevant.
- Export PDF/Excel where required.
- Print-friendly layout.
- Clear totals and subtotals.
- Source timestamp.

## Rules

- Do not overload reports with unnecessary decoration.
- Use table density suitable for print/export.
- Use consistent status colors and labels.
