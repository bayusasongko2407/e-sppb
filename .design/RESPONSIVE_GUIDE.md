# Responsive Guide

## Strategy

Desktop first, tablet supported, mobile supported.

## Rules

- Touch friendly.
- Minimum touch target 44px.
- No horizontal scrolling.
- Tables collapse to priority layout or record cards on mobile.
- Sidebar becomes drawer on mobile.
- Forms become single-column on mobile.
- Dashboard widgets reorder by workflow priority.

## Testing Viewports

- Mobile.
- Tablet.
- Desktop.
- Wide desktop.
