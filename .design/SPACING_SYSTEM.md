# Spacing System

## Tokens

- `space-0`
- `space-1`
- `space-2`
- `space-3`
- `space-4`
- `space-5`
- `space-6`
- `space-8`
- `space-10`
- `space-12`

## Rules

- Do not hardcode spacing.
- Use consistent vertical rhythm.
- Dense operational components use compact spacing tokens.
- Forms use enough spacing to distinguish groups and errors.
- Page sections should not become nested cards.
