# Table Standard

## Required Capabilities

Every table must support:

- Search.
- Quick filter.
- Advanced filter.
- Sorting.
- Column resize.
- Column visibility.
- Pagination.
- Bulk action.
- Export.
- Import where relevant.
- Sticky header.
- Responsive layout.
- Empty state.
- Loading state.
- Permission-aware actions.

## Density

Provide compact, standard, and comfortable density where practical.

## Row Actions

Common row actions should be predictable: view, edit, submit, approve, reject, revision, export. Permission checks must be enforced beyond visibility.

## Responsive

On mobile, collapse rows into readable record cards or priority-column layouts. Avoid horizontal scrolling.
