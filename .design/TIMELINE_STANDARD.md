# Timeline Standard

## Usage

Use timeline for approval history, status logs, document lifecycle, activity logs, and audit trails.

## Timeline Item Content

- Action.
- Actor.
- Timestamp.
- Old status and new status where relevant.
- Notes/reason.
- Related attachment or validation link when relevant.

## Rules

- Most recent first unless a process view needs chronological order.
- Status colors must use semantic tokens.
- Audit data must not be hidden behind decorative UI.
