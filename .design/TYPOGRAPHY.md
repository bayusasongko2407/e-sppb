# Typography

## Principles

Typography must support scanning, data density, and long daily use.

## Scale

- `text-xs`: metadata, helper text.
- `text-sm`: dense table and secondary UI.
- `text-md`: default body and form fields.
- `text-lg`: section headings.
- `text-xl`: page titles.
- `text-2xl`: dashboard or report headings only.

## Weight

- `font-regular`: normal body.
- `font-medium`: labels, table headings.
- `font-semibold`: page titles, important status.
- `font-bold`: use sparingly.

## Rules

- Do not scale font size with viewport width.
- Letter spacing is `0`.
- Avoid oversized text inside dense operational panels.
- Labels must be concise and consistent.
