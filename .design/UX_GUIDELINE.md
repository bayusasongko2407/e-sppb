# UX Guideline

## Core UX Principles

- Reduce clicks.
- Reduce scrolling.
- Reduce typing.
- Keep user context.
- Prevent user mistakes.
- Always show meaningful feedback.
- Never surprise the user.
- Prioritize frequent workflows.

## Workflow UX

- Show current state and next allowed actions.
- Explain why an action is unavailable.
- Preserve drafts for long forms.
- Confirm destructive actions.
- Keep approval decisions fast but deliberate.

## Feedback

- Loading state for async operations.
- Success confirmation after completion.
- Inline validation before submission where practical.
- Clear error recovery path.
