# Phase 0 Playbook

## Objective

Prepare repository as an enterprise AI-driven project. Do not implement Laravel application code.

## Steps

1. Preserve `/docs`.
2. Read Markdown documentation.
3. Read blueprint YAML when extracting database/domain knowledge.
4. Create AI support directories.
5. Create `AGENTS.md`.
6. Create `.codex` operational knowledge base.
7. Create prompt library, templates, playbooks, checklists, knowledge, decision-tree, and memory.
8. Verify structure.

## Completion Criteria

- `AGENTS.md` exists.
- `.codex` guides exist.
- Repository map exists.
- Prompt library exists.
- Checklists exist.
- Knowledge files are generated from `/docs`.
